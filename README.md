## ✨ Features

- User-friendly web interface
- Flask backend
- PDF processing
- Responsive design

## ⚙️ How to Run Locally

1. Clone the repository
2. Install dependencies:

   pip install -r requirements.txt

3. Run the application:

   python app.py

4. Open the local URL shown in the terminal.
